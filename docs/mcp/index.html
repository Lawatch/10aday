Exact developer-file tools for AI assistants (MCP servers)

AI assistants often guess how git, npm, Node, Docker and browserslist read their config files, and guess wrong. Each server below computes the answer with the real rules, ported from the real tool and checked against it on tens of thousands of cases (0 differences). One click to install in Claude Desktop, VS Code or Cursor.
