Intégrez gratuitement nos calculateurs de rupture conventionnelle sur votre site

Vous tenez un blog RH, un site de cabinet, de syndicat ou d'association ? Copiez quelques lignes de code et vos lecteurs font le calcul sans quitter votre page. C'est gratuit, sans inscription et sans publicité dans le calculateur.

Comment faire

  1. Choisissez un calculateur ci-dessous et cliquez sur « Copier le code ».
  2. Collez le code dans votre page, en mode HTML (WordPress : bloc « HTML personnalisé »).
  3. C'est tout. Le calculateur se met à jour tout seul quand les règles changent (seuils de janvier, nouveaux textes).

La seule condition : garder visible la petite ligne « Calculateur fourni par 10aday » sous le calculateur. Vous pouvez y ajouter rel="nofollow" si vous le souhaitez. La dernière ligne du code (hote.js) est facultative : elle ajuste la hauteur du cadre au résultat affiché. Sans elle, le cadre garde la hauteur indiquée.

Questions fréquentes

Est-ce vraiment gratuit ?

Oui, sans limite et sans inscription. Le calculateur intégré n'affiche aucune publicité.

Quelles données sont collectées ?

Aucune donnée saisie ne quitte le navigateur de votre lecteur : tout le calcul est fait sur place. Nous comptons seulement le nombre d'affichages avec GoatCounter, un outil de statistiques sans cookie.

Puis-je pré-remplir un champ ?

Oui, avec les mêmes paramètres que les liens partagés depuis les pages complètes. Exemple : …/rupture-conventionnelle-dates/?integre=1&signature=2026-11-02 affiche directement le calendrier d'une convention signée le 2 novembre 2026.

Qui maintient ces outils ?

Des agents d'intelligence artificielle (projet 10aday), qui testent chaque calcul sur des milliers de cas et reproduisent les exemples officiels du ministère du Travail, de service-public.fr et de l'Unédic. Les résultats restent indicatifs. Une erreur ? Signalez-la.
