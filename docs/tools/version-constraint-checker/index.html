Pre-releases: each tool has its own rule

ToolWhat this page shows for a pre-release such as 1.3.0-rc.1
npmA pre-release matches only if one comparator in the same range names the same major.minor.patch with a pre-release tag. For example, ^1.2.3-beta accepts 1.2.3-rc.1 but not 1.3.0-rc.1. Option includePrerelease is off.
CargoSame idea as npm (Rust crate semver): pre-releases are rejected unless a comparator names one on the same major.minor.patch.
ComposerThe constraint itself includes pre-releases: ^1.2 covers 1.3.0-RC1. At install time, minimum-stability (default stable) filters them out unless you lower it or add a flag such as @RC. This page shows the constraint check only.
pipThis page shows PEP 440 range membership with pre-releases allowed. pip itself installs a pre-release only with --pre, when the specifier names a pre-release, or when no final release matches. Note that <2.0 never matches 2.0.0a1.
RubyGemsPre-releases (1.3.0.rc1, or 1.3.0-rc.1 read as 1.3.0.pre.rc.1) sort before the release and are compared normally. gem install and Bundler only pick them when you ask for pre-releases.

Common questions

What is the difference between tilde (~) and caret (^) in npm?

~1.2.3 allows patch updates only (≥1.2.3 <1.3.0). ^1.2.3 allows minor and patch updates (≥1.2.3 <2.0.0). Below 1.0.0 the caret is stricter: ^0.2.3 means ≥0.2.3 <0.3.0, and ^0.0.3 means exactly the 0.0.3 line. Cargo reads both operators the same way.

What does tilde mean in Composer?

Composer's tilde lets the last number you wrote move: ~1.2 means ≥1.2 <2.0, while ~1.2.3 means ≥1.2.3 <1.3.0. Coming from npm, ~1.2 is the classic surprise.

What does ~> (pessimistic operator) mean in a Gemfile?

~> 2.1 means ≥2.1 and <3.0, and ~> 2.1.0 means ≥2.1.0 and <2.2. RubyGems drops the last number you wrote and bumps the one before it.

What does ~= (compatible release) mean in pip?

~=1.4.2 means ≥1.4.2 and ==1.4.*. ~=1.4 means ≥1.4 and ==1.* (any 1.x from 1.4). It works like Ruby's ~>. npm also accepts ~=, but reads it as its own tilde.
